QR Code

For the table cards and the order-of-service signs

How to use this

  1. Deploy the site first, then paste the live address above. The code regenerates as you type — there is nothing to reinstall.
  2. Download SVG for anything printed. It is vector, so it stays sharp at any size, from a place card to an A1 welcome board.
  3. Download PNG for WhatsApp, Instagram or email.
  4. Download table card gives you a finished A6 card (105 × 148 mm) with your names, the date and the code — send it straight to a printer.
  5. Print the code at 3 cm or larger, keep the pale border around it, and never place it on a busy photograph. Dark ink on a light background scans best in dim reception lighting.
  6. Test it with two or three different phones before you print a hundred.

The encoder runs entirely in this page — error-correction level M, which survives a creased or slightly smudged card.
